Project 1: QUASAR

Live Demo GitHub

Quasar is a collaboration platform that I developed to help students and developers find projects, build teams, and work together more efficiently. I wanted to create a system that goes beyond simple project listings by using AI-powered recommendations to intelligently match users based on their skills, interests, and experience. The platform includes real-time chat, task management, authentication, and project collaboration features, and was built using Spring Boot, React, PostgreSQL, WebSockets, and a Python-based recommendation engine.
